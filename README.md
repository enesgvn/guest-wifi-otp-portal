## Configuration Notice

This project is provided as a generic reference implementation.

Before using it in your own environment, you must configure all network-specific values according to your infrastructure, including:

- Firewall / FortiGate API endpoint
- API token and permissions
- Address group names
- Guest VLAN and subnet information
- Captive portal URL
- SMS provider credentials
- Database credentials
- Session duration and DHCP lease strategy

No default IP address, domain, API token, firewall object name, or organization-specific value is intended for production use.

Always review and adapt the configuration to match your own network design and security requirements.
